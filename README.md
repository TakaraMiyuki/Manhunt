# 猎人游戏 Manhunt

Minecraft Java 26.2 / NeoForge 26.2 猎人追杀玩法模组（测试版 0.2.0-beta）。

灵感来自 Dream 的猎人游戏：**逃生者**在躲避追杀的同时沿检查点链前进并击杀末影龙获胜；**猎人**负责追杀所有逃生者。

## 0.2.0-beta 大版本更新

- **检查点无限链**：数量不限，间隔 400~600 格逐个解锁；任一逃生者里程 ≥3000 后，下一个检查点固定为**末地要塞**（要塞上方地表），激活后进入杀龙阶段
- **里程系统（逃生者）**：每水平移动 1 格积 1 里程，每 200 里程触发一次**资源抽奖**；里程量表占用经验条（进度=里程/200，等级=抽奖次数）。**进入末地后不再累计里程**
- **资源抽奖**：屏幕上方的老虎机动画（下移避让 bossbar），动画结束后进入**领取模式**——滚轮/←→ 选择、中键/回车 领取选中项、右键 一键收取全部；触发下一次抽奖时未领取的奖励自动入包。奖池按里程分四档（<1000 / <2000 / <3000 / 3000+），**食物与合成材料/消耗品为主，装备为低权重稀有项**；2000+ 附魔书权重提升，3000+ 出现**满级高级附魔书**
- **合成栏附魔**：附魔书 + 可附魔装备 放入合成格即可附魔（同名同级 +1、异级取高，受附魔上限约束，无需铁砧与等级）
- **士气系统（猎人，全队共享）**：对逃生者每造成 1 点实际伤害 +1 士气，达到 50/100/200/300/500/700/1000（封顶）时**每个在线猎人各触发一次超级抽奖**（全档位池 7 种物品）；士气量表占用经验条
- **技能栏（可选依赖 skillcards）**：快捷栏**最右一格**为固定技能槽，抽到的所有技能卡（含彩卡）进入个人技能库不占背包，槽位显示激活的卡——**右键使用技能，左键切换**（持卡时左键方块/实体=切换，挥空=切换）；激活检查点 → 激活者抽一张卡（要塞固定彩卡）+ 全体存活逃生者超级抽奖；卡牌概率 普通 68% / 稀有 20% / 黑卡 10% / 彩卡 2%
- **经验条接管**：参与者不再获取/掉落经验，经验球也不会跟随参与者（避免环绕无法吸收）
- **动态档位**：按 猎人:存活逃生者 比值实时调整双方性能（见下表），档位变化全服广播
- **死亡规则**：猎人/逃生者死亡均不产生掉落物；猎人装备保留到复活；逃生者死亡即淘汰（转旁观）
- **击杀奖励**：逃生者击杀猎人 → 击杀者恢复 20% 最大生命
- **免伤规则**：末影龙与末影人无法对猎人造成伤害（含龙息/龙火球/拍击）
- **抽奖动画**：淡入 → 滚动（变调 tick 音）→ 各槽依次定格（按品质升调）→ 淡出；技能卡为单卡翻转 + 品质色光晕脉冲。贴图路径预留 `assets/manhunt/textures/gui/loot/`，放入自定义贴图即可替换程序化绘制

## 安装

- 模组 jar：`build/libs/manhunt-0.2.0-beta.jar`，放入 NeoForge 26.2 实例的 `mods/` 文件夹（服务端/客户端都要装）
- 依赖声明为 `[26.2.0.82,)`，在 26.2.0.88 实例上可正常加载
- 可选联动：同时安装 [SkillCards](https://github.com/TakaraMiyuki/SkillCards)（0.1.0-beta+）启用技能卡

## 游戏流程

1. **开局**：`/manhunt admin team add hunter|runner <玩家>` 指定角色（或 `start random <猎人数>` / `start solo` 单人调试），然后 `start`。全员传送到出生点集合，60 秒逃跑倒计时（猎人被定身且无法伤害逃生者）
2. **追逐**：猎人获得追踪罗盘（右键切换目标）；逃生者沿罗盘/bossbar 引导依次激活检查点，跑图攒里程触发资源抽奖
3. **末地**：里程达标 → 要塞检查点（固定彩卡+超级抽奖）→ 进要塞传送门（末地强化）→ 击杀末影龙获胜
4. **胜负**：龙死逃生者胜；逃生者全部淘汰猎人胜（solo 模式不结算）

## 指令

管理类需 OP 权限 2，位于 `/manhunt admin ...`：

| 指令 | 说明 |
| --- | --- |
| `team add hunter\|runner <玩家>` / `team clear` | 队伍管理 |
| `start` / `start random <猎人数>` / `start solo` | 开局（solo=无猎人的单人调试，死亡不结算） |
| `stop` | 终止对局 |
| `debug status` | 里程/士气/档位/检查点/成员总览 |
| `debug mileage add\|set <n>` | 调试里程（会补触发抽奖） |
| `debug morale add\|set <n>` | 调试士气（会补触发超级抽奖） |
| `debug draw` / `debug superdraw` | 手动资源/超级抽奖 |
| `debug card [common\|rare\|rainbow\|black]` | 手动抽技能卡 |
| `debug slot set <1-4>\|auto` | 锁定/恢复人数档位 |
| `debug nextcp stronghold` | 强制下一个检查点为要塞 |
| `debug unlock` / `debug tp <n>` / `debug compass <玩家>` | 旧调试指令 |
| `/manhunt status` | 所有玩家可查的简要状态 |

## 持久化与测试

- 对局状态（含里程/士气/检查点链）保存在 `world/manhunt_state.json`，服务器重启后恢复（倒计时无法跨重启，统一按追逐阶段恢复）
- 无玩家冒烟测试：`MANHUNT_SMOKETEST=1 ./gradlew runServer`，自动生成检查点、抽样全部奖池、验证技能卡桥接（需将 skillcards jar 放入 `run/mods/`）

## 开发

- 构建插件 ModDevGradle 2.0.146 / Gradle 9.2.1 / JDK 25
- 编译期使用 NeoForge **26.2.0.82**：0.88 的依赖组合会触发 NFRT 重编译失败（`HolderSet` 源码编译冲突），运行依赖范围为宽区间不受影响
- 编译期引用 `../SkillCards/build/libs/skillcards-0.1.0-beta.jar`（可选联动，全部 skillcards 类引用收敛在 `cards/SkillCardsBridge`）
- 所有数值集中在 `src/main/java/com/example/manhunt/GameConfig.java`，性能档位表在 `game/TierSystem.java`

## 已知限制（测试版）

- 经验条被量表接管：参与者的 XP 获取与掉落已禁用（经验瓶无效），等级数字复用为抽奖/士气档数
- 检查点标记为原版方块组合，未做防破坏保护
- 抽奖动画为程序化原版风格（预留贴图位：`assets/manhunt/textures/gui/loot/`），精细素材到位后无需改代码即可替换
- 逃跑倒计时期间里程照常累计、抽奖照常触发
