# 猎人游戏 Manhunt

Minecraft Java 26.2 / NeoForge 26.2 猎人追杀玩法模组（测试版 0.1.0-beta）。

灵感来自 Dream 的猎人游戏：**逃生者**在躲避追杀的同时依次激活 4 个检查点并击杀末影龙获胜；**猎人**负责追杀所有逃生者。

## 安装

- 模组 jar：`build/libs/manhunt-0.1.0-beta.jar`，放入 NeoForge 26.2 实例的 `mods/` 文件夹（服务端/客户端都要装）。
- 依赖声明为 `[26.2.0.82,)`，在 26.2.0.88 实例上可正常加载。
- 需要所有人重新登录客户端才会显示两个自定义罗盘物品的模型（本体服务端可运行）。

## 游戏流程

1. **开局**：管理员执行 `/manhunt team add hunter|runner <玩家>` 指定角色（或 `/manhunt start random <猎人数>` 随机分配），然后 `/manhunt start`。
   - 所有参与者被传送到世界出生点集合。
   - 60 秒逃跑倒计时：猎人被施加缓慢 VI + 虚弱 + 盲目，且无法对逃生者造成伤害；逃生者获得初始装备（石剑/石镐/石斧/泥土×64）与**检查点罗盘**。
2. **检查点**：共 4 个，逐个解锁，只在激活后才会解锁下一个的坐标。
   - 1 号：距出生点 1000~1500 格；2/3 号：距上一检查点 500~800 格，随机方向，地表选址（避开海洋/河流/沙滩与水面）。
   - 4 号：固定在最近的**末地要塞**正上方地表。
   - 标记为 3×3 金块平台 + 荧石柱；逃生者靠近 6 格内自动激活。
   - 激活后全体存活逃生者获得物资（稀有度递增）：1 号基础生存、2 号钻石/金苹果/力量药水等、3 号随机附魔书/图腾等、4 号固定**鞘翅 + 末影之眼×12** + 随机补给。
   - 逃生者罗盘始终指向当前目标检查点；bossbar 显示进度与距离。
3. **猎人**：追逐阶段获得**追踪罗盘**（速度1/急迫1/40 血），右键循环切换追踪目标逃生者。
4. **死亡规则**：
   - 逃生者击杀猎人 → 全体逃生者获得生命恢复 III（5 秒）。
   - 猎人复活在"距最近逃生者 >300 格的存活猎人中最远者"附近（20~40 格）；无合格者则复活在上一个已激活检查点，再退到世界出生点。
   - 猎人在**末地**被击杀 → 复活在 4 号检查点附近 100 格（主世界）。
   - 逃生者死亡即淘汰（转旁观）；全部淘汰则猎人获胜。
   - 逃生者进入末地获得强化：抗性 2 / 速度 1 / 跳跃提升 2 / 饱和 1 / 急迫 2，返回主世界自动还原。
5. **胜负**：末影龙死亡 → 逃生者胜；全部逃生者被淘汰 → 猎人胜。

## 指令（OP 权限 2）

| 指令 | 说明 |
| --- | --- |
| `/manhunt team add hunter <玩家>` | 设为猎人（可多选） |
| `/manhunt team add runner <玩家>` | 设为逃生者 |
| `/manhunt team clear` | 清空队伍 |
| `/manhunt start` | 用已指定角色开局 |
| `/manhunt start random <猎人数>` | 从在线玩家随机分配开局 |
| `/manhunt stop` | 终止对局 |
| `/manhunt status` | 查看对局状态与检查点坐标 |
| `/manhunt debug unlock` | 强制激活当前检查点（测试用） |
| `/manhunt debug tp <1-4>` | 传送到指定检查点 |
| `/manhunt debug compass <玩家>` | 补发对应阵营罗盘 |

## 持久化与测试

- 对局状态保存在 `world/manhunt_state.json`，服务器重启后恢复（倒计时无法跨重启，统一按追逐阶段恢复）。
- 无玩家冒烟测试：环境变量 `MANHUNT_SMOKETEST=1` 启动服务器，自动生成检查点并输出坐标/间距（`./gradlew runServer` 前设置）。

## 开发

- 构建插件 ModDevGradle 2.0.146 / Gradle 9.2.1 / JDK 25。
- 编译期使用 NeoForge **26.2.0.82**：0.88 的依赖组合会触发 NFRT 重编译失败（`HolderSet` 源码编译冲突），运行时依赖范围为宽区间不受影响。
- 所有数值集中在 `src/main/java/com/example/manhunt/GameConfig.java`，改完 `./gradlew build` 重新出包即可。

## 已知限制（测试版）

- 检查点标记为原版方块组合，未做防破坏/防挖掘保护。
- 猎人在末地复活回主世界是按需求字面实现的，若要复活在末地内需调整 `RespawnSelector`。
- 追踪罗盘的指向通过服务端每秒写入 `LODESTONE_TRACKER` 组件实现，跨维度时按原版行为指针旋转。
