## 1. 模组构成与安装

| 模组 | mod id | 定位 | 是否必需 |
| --- | --- | --- | --- |
| 猎人游戏 Manhunt | `manhunt` | 主玩法：追逐对抗、检查点、里程与士气、抽奖 | **必需** |
| 技能卡 SkillCards | `skillcards` | 联动：技能卡抽取与使用、合成栏附魔 | 可选 |
| 飞翔 Flying | `flying_enchant` | 独立模组：重锤附魔"飞翔"与同名状态效果（星月/海王之翼的底层） | 可选 |

- 三个 jar 均放入 NeoForge 26.2 实例的 `mods/` 文件夹，客户端与服务端都要安装。
- 未安装 SkillCards 时 Manhunt 主玩法完整可玩，仅跳过抽卡环节；未安装 Flying 时"海王之翼"卡无法正常使用。
- Manhunt 与 SkillCards 双向声明可选依赖（运行期互为增强，缺失时自动降级）。

## 2. 核心玩法流程

灵感来自 Dream 的猎人游戏：**逃生者**在躲避追杀的同时沿检查点链前进并击杀末影龙获胜；**猎人**负责追杀所有逃生者。

```
开局集合（全员传送世界出生点）
   │  60 秒逃跑窗口：猎人被定身（缓慢Ⅵ+虚弱+失明）且无法伤害逃生者
   ▼
追逐阶段 ── 逃生者：跑图积里程 → 每 200 格资源抽奖 → 依次激活检查点 → 抽技能卡
   │                 猎人：追踪罗盘锁定目标 → 伤害积累全队士气 → 超级抽奖
   ▼
任一逃生者里程 ≥ 3000 → 下一个检查点固定为【末地要塞】（要塞正上方地表）
   │  激活要塞检查点：激活者固定抽到彩卡，全队获末影之眼×12
   ▼
进入末地（逃生者获得末地强化，里程停算）
   │
   ▼
击杀末影龙 → 逃生者获胜    ｜    逃生者全部淘汰 → 猎人获胜
```

- **胜负判定**：末影龙死亡瞬间逃生者阵营获胜；所有逃生者被淘汰（转旁观模式）则猎人获胜。对局重置时清空参与者背包。
- 每局节奏约 30–60 分钟（跑图积累 → 检查点博弈 → 末地决战）。

## 3. 阵营与动态性能档位

双方性能按 **猎人 : 存活逃生者** 的人数比实时切换（每 2 秒重算，调试可锁定），档位变化全服广播。括号内为进入末地后的数值：

| 人数比 | 猎人 | 逃生者 |
| --- | --- | --- |
| ≤ 1:1 | 60 血 · 速度2 · 急迫2 | 60(80) 血 · 抗性1 · 急迫2 · (速度2)(跳跃提升2) |
| ≤ 2:1 | 40 血 · 速度2 · 急迫2 | 60(80) 血 · 抗性1 · 急迫2 · (速度1)(跳跃提升2) |
| ≤ 3:1 | 40 血 · 速度1 · 急迫2 | 60(100) 血 · 抗性1 · 急迫2 · (速度1)(跳跃提升2) |
| > 3:1 | 40 血 · 速度1 · 急迫2 | 80(100) 血 · 抗性1(2) · 急迫2 · (速度1)(跳跃提升2) |

- 所有增益由服务端每 2 秒强制刷新，死亡/牛奶/切维度后自动恢复。
- 猎人额外免疫：**末影龙与末影人不会攻击猎人**，龙息/龙火球/拍击等对猎人的伤害被完全取消；末影人的索敌目标会被强制移除。

## 4. 检查点系统

| 项目 | 数值/规则 |
| --- | --- |
| 数量 | 不限，组成"检查点链"，激活当前后才生成/解锁下一个 |
| 间距 | 相邻 400–600 格随机方向；1 号距世界出生点 400–600 格 |
| 选址 | 高度图取地表（同步加载区块），排除海洋/河流/沙滩群系与水面 |
| 标记 | 黄色粒子圈（半径与触发范围一致，激活后变绿保留 10 秒），无实体方块 |
| 激活 | 逃生者进入 **6 格水平距离**内自动激活（忽略 Y 差——树冠下/悬崖边均可触发） |
| 引导 | 逃生者人手一枚**检查点罗盘**（实时指向当前目标）+ bossbar（进度与直线距离） |
| 结算 | 激活者抽一张技能卡（要塞检查点固定彩卡）+ 全体存活逃生者各获一次**超级抽奖** |
| 要塞切换 | **任一**逃生者里程 ≥ 3000 后，下一个检查点固定刷新在**末地传送门房间的正上方**（自动定位要塞内的传送门房间 piece）；激活后不再生成后续检查点，目标转为击杀末影龙 |
| 要塞物资 | 末影之眼 ×12（足够填满传送门并留余量）；鞘翅仅能通过四档抽奖低概率获取 |

## 5. 里程与资源抽奖

### 5.1 里程（双方量表）

- 每水平移动 **1 格 +1 里程**；单刻位移 > 10 格（传送/坠落）不计；**进入末地后停止累计**。
- **猎人同样累计里程，但获取效率为逃生者的 1/2**；每 200 里程同样触发资源抽奖（相同四档奖池与待领取交互）。要塞切换与检查点链仍只看逃生者里程。
- **经验条被接管为里程量表**（双方通用）：进度 = 距下次抽奖的里程比例，等级数字 = 已触发抽奖次数。参与者的经验获取与掉落全部禁用，经验球也不会跟随参与者（避免环绕无法吸收）。

### 5.2 资源抽奖

- 每 **200 里程**触发一次：抽出 **5 种**物品（可重复），服务端立即结算。
- 抽奖走**加权随机**——食物与合成材料/消耗品占大头，装备为低权重稀有项。
- 奖池按里程分四档（`MILEAGE_TIERS = 1000/2000/3000`）：

| 档位 | 定位 | 代表内容 |
| --- | --- | --- |
| < 1000 | 生存补给（59 条 / 权重 101） | 面包 1–8（权重 7）/浆果/生肉/南瓜、圆石/木板/原木、沙砾/雪块/燧石、火把 ×24–64、箱子/熔炉/树苗、木石工具与皮甲（低权重）、金/链/铜头盔与铁靴/铁锄（低权重） |
| < 2000 | 冒险补给（64 条 / 权重 109） | 面包/熟肉/烤马铃薯、铜锭 ×4–12/铁锭/金锭、玻璃/梯子/骨头、牛奶/荧石/望远镜/樱花木船、铜铁工具与**长枪**、铜甲/链甲（低权重）、药箭（迟缓/虚弱/剧毒）、迅捷Ⅱ/跳跃Ⅱ药水 |
| < 2000–3000 | 精良补给（76 条 / 权重 121） | **随机附魔书 ×2（权重 5×2）**、南瓜派/面包大份、钻石 1–2/绿宝石 10–25、黑曜石/深板岩圆石、风弹/TNT/烈焰弹、打火石/附魔台/磁石/苦力怕头、锁链/金/铁甲与长枪、药水（再生Ⅱ/跳跃Ⅱ/迅捷Ⅱ、喷溅伤害Ⅱ、滞留神龟Ⅱ）、神龟/凋零Ⅱ药箭 |
| ≥ 3000 | 顶级补给（66 条 / 权重 146） | **满级高级附魔书 ×2（权重 6×2）**、末影之眼 ×3–6（权重 5）、钻石 ×3–4、末影珍珠/风弹/TNT/岩浆桶、金苹果/附魔金苹果、药水（力量Ⅱ/抗火长效/迅捷长效/夜视长效/缓降、喷溅伤害Ⅱ）、三叉戟/重锤/**鞘翅**/不死图腾/下界合金锭与升级模板/末影水晶（低权重） |

- **2000 里程后**附魔书出现概率显著提升；**3000 里程后**出现"满级高级附魔书"（直接给到该附魔的最高等级）。
- 附魔书为动态条目：从锋利/效率/保护/时运/精准采集/经验修补/摔落缓冲/力量/无限等 29 种正面附魔中随机。

### 5.3 待领取交互（滚轮/中键/右键）

抽奖结果不直接入包，而是停留在屏幕上方的老虎机界面（时长 4.5 秒动画 + 选中名称行，不锁视野与操作）：

| 操作 | 默认键位 | 行为 |
| --- | --- | --- |
| 选择 | 鼠标滚轮 / ← → | 移动白色游标；选中物品在名称行显示名称（附魔书附附魔名与等级）与 ×数量 |
| **标记** | **鼠标中键**（可在设置中改绑） | 给选中物品打金色常驻边框，可多选、再按取消 |
| **领取** | **鼠标右键**（可改绑） | 领取**全部已标记物品**入包并关闭界面；一个都没标记时领取当前选中项；**未标记物品直接丢弃** |
| 超时 | — | 触发下一次抽奖时，本轮未领取的奖励视为放弃（不发放）；掉线重连与游戏结束则为入包补偿 |
| 暂离 | **鼠标左键** | 暂时脱离抽奖界面（面板置灰，滚轮/右键等恢复正常操作），**中键** 返回；技能抽奖与资源抽奖同时存在时，左键**一并脱离**两者；暂离期间刷新的抽奖会重新回到界面 |
| 积攒 | — | **里程值资源抽奖**之间相互覆盖（当前轮未领取又攒满一轮 → 放弃当前轮开新轮）；其余来源（超级抽奖/补给光柱等）一律**顺延**在当前轮之后（非批量时顺延槽位最多一个）；**同一刻批量到达**（如赏金量表一次连升数档）全部保留、依次开启 |
| 超级抽奖 | — | 只出现**不低于当前里程档**的物资 |

- 超级抽奖（7 种物品，不限奖池）使用完全相同的交互。
- **合成栏附魔**：附魔书 + 可附魔装备放进合成格 → 直接附魔（同名同级 +1、异级取高，均不超过附魔上限），无需铁砧与经验等级。

## 6. 技能卡系统（联动 SkillCards）

- **获取**：每激活一个检查点，**全体存活逃生者各抽一张技能卡**（人人有份）；激活者额外享受 **要塞检查点固定抽到彩卡**。
- **概率（加权随机）**：权重 普通 54 · 稀有 30 · 黑卡 30 · 彩卡 4（合计 118 → 约 45.8% / 25.4% / 25.4% / 3.4%）。**每张未拥有卡按其品级权重参与加权抽取**——某品级集齐后自动退出权重池，整体分布全程保持。**同一张卡不会重复抽到**，全部集齐后跳过。
- **超级疾跑**：默认键 **C**（可改键）。
- **技能库**：所有抽到的技能卡（含彩卡）进入个人虚拟技能库，**上限 8 张**（超出直接丢弃；单人调试模式不限）、不占背包、随对局持久化；槽位始终显示"激活"的那张。
- **技能栏（0.3.4 新交互）**：全部主动卡收纳于 **9 格隐藏快捷栏**。**按住左 Alt** 时热栏临时替换为技能栏（暗金边框、原版交互）——滚轮/数字键 1-9 切换选中格（选中技能的**卡名与效果概述**实时显示在技能栏上方），**右键释放**选中技能（原版冷却灰罩），**按住左键**查看技能详情（卡名/概述/全文/剩余冷却）；松开 Alt 恢复原本快捷栏。
- **背包查看**：打开背包可在热栏行下方看到暗金边框技能栏——可随时**调整技能顺序**（两次点击移动/交换）；调试模式与未开局时可放入/取出技能卡。
- **守护**：快捷栏（除技能槽）不允许存放**主动卡**（镜像副本自动清理防复制）；**被动卡**例外——背包中同样生效。
- **被动卡与饰品栏**：被动卡（无主动使用、常驻生效，如攻势/多重/法轮等 13 张）抽到后**自动放入 6 格专属饰品栏**（由 Curios 提供，物品需在 `curios:skill_passive` tag）；饰品栏或背包中即持续生效，最多 6 张（满后再抽到被动卡自动丢弃）；饰品栏中的被动卡同样计入"不可重复抽取"。脱离对局时清空。**0.3.4 修复：饰品槽位此前未绑定玩家实体导致不出现，已在槽位数据中补 entities 声明。**

## 7. 猎人士气系统

- **积累**：猎人对逃生者每造成 1 点实际伤害（减伤后），全队共享士气 +1。
- **奖励阈值**：50 / 100 / 150 / 200 / 300 / 400 / 600，**此后每档固定 +200，无封顶**（800 / 1000 / 1200…）。每达到一档，**每个在线猎人各触发一次超级抽奖**（7 种物品，不限里程奖池）。
- **量表**：在猎人屏幕上方以**原版 bossbar 雪碧图**样式显示（蓝色进度条 + 士气值与档数标注，位于原版 bossbar 区域下方）；士气增长后 5 秒内量表会临时接管猎人的经验条。

## 8. 对抗规则细则

| 规则 | 内容 |
| --- | --- |
| 死亡不掉落 | 双方死亡均无掉落物（`LivingDropsEvent` 拦截）；猎人装备（含穿戴的盔甲/饰品）按**原槽位**暂存并在复活时**回穿**；逃生者死亡即淘汰、转旁观 |
| 友军伤害 | 同阵营攻击上限 **2 点伤害**（超过被削减），但击退不受影响 |
| 击杀奖励 | 猎人死亡时，死亡点 **20 格内**的所有存活逃生者（含击杀者，击杀者不限距离）各恢复最大生命的 **15%** |
| 猎人复活 | 死亡后**立即自动重生**为 **10 秒旁观者**，随后传送至复活点并公告坐标：① 距最近逃生者 >300 格的存活猎人中取**最近者**附近约 20 格；② 无合格者 → 距最近逃生者约 **500 格**的随机方向地表；掉线不丢装备与重生计划 |
| 末地覆盖 | 一旦有逃生者进入末地，全体猎人重生点变更为**末地传送门门口**（要塞传送门房间），覆盖前述规则 |
| 逃生者发光 | 全体逃生者**常驻发光**，多人时各自不同颜色描边（不用红色）区分 |
| 游泳加速 | 对局期间全体参与者的游泳速度等同于深海探索者 III（`WATER_MOVEMENT_EFFICIENCY` +1.0），结束自动移除 |
| 昼夜加速 | 昼夜时长比 **7:3**（夜间时钟加速），睡眠跳天后自动恢复 |
| 免伤 | 末影龙（拍击/冲撞/龙息/龙火球）与末影人无法对猎人造成伤害；参与者不会摔死（保底 1 颗心） |
| 信息战 | 猎人**追踪罗盘**右键循环锁定逃生者实时位置；目标进入末地后罗盘改指**末地传送门**（要塞传送门房间，猎人也在末地时指向末地中央出口）；罗盘槽位提示：**朝向明显偏离罗盘指向持续 3 秒 → 红色脉冲**（修正方向解除）、**距目标 <50 格 → 金色脉冲**；技能卡"盲点"可使其乱指（见 §9） |
| 进食加速 | 对局中参与者的进食/饮用速度约为原版 **1.5 倍** |
| 公平开局 | 60 秒逃跑窗内猎人被定身且无法伤害逃生者（伤害事件直接取消） |
| 淘汰 | 逃生者死亡即淘汰（正常旁观者）；淘汰时的未领取抽奖奖励作废 |


## 赏金猎人模式（0.3.0 新增）

`/manhunt admin start bounty [random <猎人数> | solo]`（或先用 `team add` 分队后 `/manhunt admin start bounty`）。建议配置：逃生者 3–8 人、赏金猎人 1–3 人。核心玩法不变——逃生者跑图、激活检查点、进末地杀末影龙；赏金猎人负责追杀。原生（经典）模式的全部规则在此模式下部分替换如下。

### 逃生者

| 机制 | 内容 |
| --- | --- |
| 多检查点 | 地图同时存在 **2–5 个**检查点（≤3 人→2、4–5→3、6–7→4、≥8→5），以出生点为中心 400–600 格环带分布、互相间隔 ≥400 格，可自由选择前往；每激活一个会立即刷新一个新的（维持数量上限） |

| 机制 | 内容 |

| 待领取积攒 | 一次性触发的多轮抽奖**全部排队保留**（如赏金量表连升四档 = 四轮超级抽奖依次开启），不再吞并 |
| 罗盘 | 切换目标时显示该逃生者的赏金值与排名（头号赏金为金色）；赦免中的逃生者不可被锁定 |
| 末地 | 击杀逃生者**不再获得赏金**，改为击杀者恢复 **20%** 生命 |
| 里程效率 | 赏金猎人里程积攒效率为逃生者的 **0.7 倍** |
| 装备保留 | 赏金模式下逃生者与猎人**死亡均不掉落、不丢失装备**（复活/旁观时原样归还） |
| 初始装备 | 逃生者：**木剑/木镐/木斧** + 泥土×64；赏金猎人：**石剑/石镐/石斧** + 泥土×64 |

| 动态性能 | 按"猎人数 : 存活逃生者数"比值分两档——**猎人**：60 血、抗性1、速度2、急迫2，末地追加饱和+跳跃提升1（比值 ≥1:4 时末地 80 血、速度3）；**逃生者**：40 血（末地 60）、急迫2，末地追加速度1/跳跃提升1/抗性1 |

## 10. 飞翔模组（flying_enchant）

为重锤设计的机动性附魔，1.2.0 起提供同名**状态效果**版本（海王之翼的底层）。

### 附魔版（`xingyue:flying`，重锤专用）

- **前提**：重锤必须先附魔**风爆（Wind Burst）**，否则铁砧拒绝应用飞翔附魔书。
- **触发**：下坠攻击触发风爆弹起后的空中窗口内按**跳跃键**向前上方突进；每次跃起限一次，落地或下一次弹跳刷新。
- **等级**：Ⅰ 级水平约 3 格 / 抬升 0.5 格；Ⅱ 级水平约 4 格 / 抬升 1 格（水平初速 0.44 + 0.15/级，抬升 0.24 + 0.13/级）。
- **消耗**：每次突进损耗 1 点武器耐久 + 2 点饥饿；饱食度 ≤ 6（疾跑阈值）时不可用；创造豁免。
- **适用物品**：标签 `#xingyue:enchantable/flying`（本模组提供重锤，星月模组提供星月剑，数据包 tag 自动合并）。

### 状态效果版（`flying_enchant:flying`）

- 通过命令/数据包/其他模组施加（海王之翼卡即施加此效果）：`/effect give @s flying_enchant:flying 30`。
- **触发**：效果期间**疾跑中按跳跃键**即向前上方突进并整体重置下坠速度；疾跑中空中**不限次数**连发（每次间隔 **10 刻 = 0.5 秒**冷却）；风爆弹跳后可在空中起跑接续。
- **等级**：Ⅰ 级水平约 2 格 / 抬升约 2 格（0.30 + 0.43/级 水平，0.55 + 0.17/级 垂直）；Ⅱ 级水平约 5 格 / 抬升约 3 格。
- **双持优先级**：同时拥有附魔与效果时，跃起后第一按优先消耗附魔次数，之后落到效果连发。
- **开关**：管理员可用 `/gamerule flyingDash false` 全服禁用突进。

## 12. 持久化与单人测试

- **对局状态**保存于 `world/manhunt_state.json`：阶段、已激活检查点数与当前/最近检查点坐标、全员里程与抽奖次数、士气、技能库。服务器重启后自动恢复（逃跑倒计时无法跨重启，统一按追逐阶段恢复）。
- **无玩家冒烟测试**：`MANHUNT_SMOKETEST=1`（Manhunt）会自动生成检查点、抽样全部奖池并做网络编码验证、验证抽卡分布与合成栏附魔配方；`SKILLCARDS_SMOKETEST=1`（SkillCards）校验注册与联动钩子后自动关服。
- **数值调整**：Manhunt 全部数值在 `GameConfig.java`，性能档位表在 `TierSystem.java`，奖池在 `loot/RewardPools.java`；SkillCards 在 `CardConfig.java`。修改后 `gradlew build` 重新出包即可。
- **已验证项**：编译期使用 NeoForge 26.2.0.82（0.88 工具链存在 NFRT 重编译问题，运行时依赖为宽区间不影响加载）；服务器/客户端冒烟通过；附魔书物品全程走活动注册表（避免网络编码失败）。
